# Code of Conduct

LeoTrek is committed to providing a welcoming, respectful, and
harassment-free environment for everyone participating in our
open-source projects.

LeoTrek projects follow the Contributor Covenant Code of Conduct,
version 2.1:

https://www.contributor-covenant.org/version/2/1/code_of_conduct/
