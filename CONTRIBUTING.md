# Contributing

We welcome contributions to LeoTrek! Contributions can include bug reports, feature requests, code, documentation, tests, and other improvements.

## Contribution Guidelines

For pull requests (PRs), please follow these general guidelines:

* Before submitting a PR, check whether an issue already exists describing the bug, feature, or improvement. If not, consider creating one first, especially for larger changes.
* Fork the relevant repository, make your changes in a dedicated branch, and create a PR against the main repository.
* Add or update tests for new features and bug fixes where applicable.
* Follow the existing code style and development guidelines of the repository.
* Update documentation where applicable.
* Keep pull requests focused. Unrelated changes should be submitted as separate PRs.
* Make sure your changes do not break existing functionality.

Individual LeoTrek repositories may provide additional development, testing, and contribution guidelines.
