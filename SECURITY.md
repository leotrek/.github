# Security Policy

## Reporting a Vulnerability

We take the security of LeoTrek projects seriously.

If you discover a security vulnerability, please do not report it
through a public GitHub issue, discussion, or pull request.

Please report security vulnerabilities privately via:

Email: hello@leotrek.ai

or, where available, through GitHub's private vulnerability reporting
feature.

Please include, where possible:

- The affected repository or component
- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation or fix

Please allow us reasonable time to investigate and address the issue
before publicly disclosing it.

Thank you for helping keep LeoTrek and its users secure.
